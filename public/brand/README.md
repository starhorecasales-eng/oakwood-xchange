# Cebimde Kur — Brand Assets

Public brand assets for **Cebimde Kur / Oakwood Xchange**.

## Core assets

- `logo-primary.svg` — primary horizontal logo with tagline
- `logo-primary-no-tagline.svg` — compact horizontal logo
- `logo-reversed-dark.svg` — reversed logo for dark backgrounds
- `app-icon.svg` — master app icon / scan mark

## Brand palette

- Dark green: `#102B25`
- TRY coral: `#D55B39`
- GBP blue: `#244D91`
- Warm cream: `#F4EEDF`
- Paper: `#FFFDF8`

## Concept

The four corner marks represent a camera/price scanning frame. The `₺ ↔ £` symbol communicates instant TRY/GBP conversion. The identity is designed to work for the current manual currency converter and the planned camera-based price recognition experience.

## Recommended usage

Use `logo-primary.svg` in the website header and marketing material. Use `app-icon.svg` as the source artwork for PWA, iOS and Android icon exports.
